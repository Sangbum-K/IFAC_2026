# 정적 장애물 고정 원통 대역 — run_0822_192752 1:46 회피 감속

통과 = 랩당 **1.32 s 손실**. 같은 지점에서 매 랩 반복(94.8 / 105.8 / 115.8 / 126.2).

3 회.

  p50 0.28~0.36 / p90 0.41 / max 0.478

## 변경

* `bridge/static_cylinder_band_m: [0.05, 0.25] -> [0.02, 0.44]`
  * 상한 0.44 = radius + 0.15(차 반폭). `test_static_cylinder_model_cannot_

## 검증 (브릿지 open-loop 재생, `replay_bridge_ab.zsh`)
같은 백의 `/perception/obstacles` 를 실제 브릿지 노드에 다시 먹여 A/B.

| s=12.2 물체 트랙 | half std | d_left std | 필요 d_hold p50/p90 |
|---|---|---|---|
| OLD (r0.25, [0.05,0.25]) | 0.067~0.070 | 0.073~0.088 | 0.264~0.322 / 0.365~0.382 |
| NEW (r0.30, [0.02,0.44]) | **0.014~0.027** | **0.036~0.049** | **0.244~0.268 / 0.281~0.337** |

가용 d_hold 는 이 지점 0.24~0.27 (좌경계 0.45~0.49 m 의 벽 클램프).
즉 **p90 이 0.38 -> 0.30 으로 내려와 게이트가 프레임마다 뒤집히지 않는다.**

전체 런 비용(발행 half 분포): p50 0.250 -> 0.300 (실치수 보정),
p90 0.385 -> 0.300, std 0.076 -> 0.064, half>0.35 프레임 12% -> 5%.
half<0.20 프레임은 6% -> 5% 로 거의 그대로 — 작은 검출을 부풀리지는 않는다.

## 남는 것 (이 커밋이 안 고치는 것)
1. **이 지점은 실치수 기준으로도 좌측이 빠듯하다.** 필요 d_hold p50 0.24~0.27 vs
   가용 0.24~0.27. 흔들림이 사라져 판정이 **안정**될 뿐, 무조건 열리지는 않는다.
   우측은 s=12.69 에서 트랙 우경계가 0.80 m 로 좁아져 필요치(-1.03)가 불가능하다.
2. **그립 예산 불일치.** `spliner/path_lat_acc_max = blend_lat_acc_max = 8.83`
   (mu 0.90) 인데 배포 레이스라인은 mu 1.40 (a_lat 최대 13.73, 이 구간 12.66).
   마찰원 잔여가 0 이 되어 `BlendLatAcc` 하한 2.0 고착 -> 첫 사이클 회피 속도
   캡 3.34 m/s (예산이 맞았다면 7.01 = 캡 없음), 필요 활주로 1.87 -> 3.94 m
   (인지 거리 4.14 m). 이것만으로 0.44 s. 하한 고착 구간은 트랙의 44%
   (mu1.10 라인이었다면 23%).
   ⚠️ 실측 달성 a_lat p99 는 8.76 이라 예산을 13.73 으로 올리는 것은 없는
      그립을 계획하는 것이다 — MU_PROFILE 1.40 쪽 재검토가 먼저일 수 있다.
