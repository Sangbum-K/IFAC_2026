## 2. Phase 1 — 안전 (최우선)

### P1-1  `allow_stop` 을 `is_static` 에서 분리

```cpp
// spliner_node.cpp:1754 부근
const bool allow_stop = !closest.is_static || blocked_confirmed;
```

`blocked_confirmed` = `MoreSpace` 양쪽 불가 **AND** 안정 트랙(`ObsSeen >= commit_break_min_obs`
+ `is_visible`) **AND** N 사이클 연속 (N 은 P0-1 로 결정).

과잉 정지가 안 생기는 이유: `v_target = obs.vs` 이므로 상대가 1.8 m/s 로 가면 목표도 1.8 이다.
**진짜 섰을 때만 0 이 된다.** 지금은 그 0 위에 `trailing_retry_speed` 2.5 가 덮여 있는 것이
문제다.

병합 보류(`cluster_merge_blocks_track`, 2588회)로 콘이 `closest` 가 되는 경로도 같은 조건으로
덮인다 — `MergeBlocksTrack` 이 "막힌다"고 판정한 그 쌍이 곧 `blocked_confirmed` 의 근거다.

### P1-2  escape arc 되살리기 — P0-2 결과에 따라

정지를 늘리는 변경이므로 탈출구가 함께 살아 있어야 한다. 지금은 663 s 동안 0회다.

### P1-3  `backstop_min_speed_mps` 를 경로오차 스케줄로

```
floor(e) = 1.5 · clamp((0.70 − e) / (0.70 − 0.35), 0, 1)
```

- 오차 0.35 m 이하는 **비트 단위로 동일**
- 210건 중 33건(16%)만 값이 바뀜, 그 건들 1.50 → 0.81
- 0.5 m/s 미만 비율 3% (하한 폐기 시 40%)
- 폐기(=0) 는 금지: 40% 가 사실상 정지 → 0806 라치. `BlendGeomFloor` 는 속도 무관이고

- 저속 조향 룩업이 무너지는 것이 걱정되면 페이드 하한을 0 이 아니라 0.6 으로 끊는다
  (그러면 0.5 미만 비율 0%).

| P3-2 | `trailing_gap_m` 1.5 → 0.75 (= 꽁지 0.30). `trailing_floor_gap_aware` 캡을 추월 준비 상태에서 재범위 | 지터 std 0.126 이라 여유 0.30 안쪽. 10프레임 평균이면 0.040 |
| P3-3 | 횡이동과 속도 부스트 3단 분리: 속도 맞춤 → 횡이동 완료 → 가속 | 지금은 `ot_speed_scale` 1.25 / `dyn_pass_speed_ratio` 1.15 가 동시에 걸려 빠지는 도중 붙는다 |

**P3-2 는 P1-1 이 들어간 뒤에만.** 지금은 `trailing_gap_m` 1.5 가 정지 장치를 대신하고 있다.

위험: 상대 감속 p99 2.56 m/s² 에서 0.30 m 꽁지는 0.52 s 뒤 **상대속도 0.91 m/s** 로 접촉한다
(가벼운 탭). p90 1.20 에서는 접촉 없음.

## 5. 시뮬 테스트 리스트

### 공통 세팅

```bash
ros2 launch planning_pkg sim_race.launch.py \
    map:=my_track0817 env:=sim_real_car vehicle:=real_car perception:=lidar
```

- `env:=` 를 빼면 환경 yaml 이 검증되지 않는다 (0820 회귀 사례).
- **`perception:=lidar` 필수.** 기본 `ground_truth` 는 GT 주입이라 탐지 지평(4.1 m)과
  간격 지터(0.126)가 재현되지 않아 이 계획의 전제가 통째로 사라진다.
- 상대 스폰: RViz `2D Goal Pose`. 모드/속도는 `/sim/opp_mode`, `/sim/opp_speed_delta`
  (`opponent/mode: path` = 레이스라인 pure pursuit, `opponent/speed_scale` 기본 0.255
  ≈ 실차 RC 와 같은 속도).
- 정적 장애물은 `/clicked_point`. sim 전용 리맵을 쓸 것 — 안 그러면 PF 가 전역 재초기화된다.
- numpy/skimage 는 user-site 를 쓴다. `PYTHONNOUSERSITE` 를 걸지 말 것.
