## 1. Control — 수정 대기 (4건)

### C1. ★ 계획속도 0 → 조향 0  (P0, 최우선 · 한 줄)

**위치** `control_ws/src/control_pkg/src/control_node.cpp:1057-1080`

```cpp
const double steering_lookahead_speed = waypoints[idx].vx_mps;      // ← 계획 속도
const double speed_for_lookup = speed_adjust_lat_err(steering_lookahead_speed, ...);
lateral_acceleration = 2.0 * speed_for_lookup*speed_for_lookup / l1_distance * sin(eta);
double steering_angle = lookup_steer_angle(lateral_acceleration, speed_for_lookup);
```

MAP 컨트롤러의 조향은 **실측 속도가 아니라 웨이포인트의 `vx_mps`** 로 계산된다.
플래너가 `vx_mps = 0`을 실으면 → `a_lat = 0` → LUT의 zero-steering 행
(`control_node.cpp:246`) → **조향각 정확히 0**. 차가 3.2 m/s로 달리고 있어도 그렇다.

**실측 (164216)**

| t | 경로 vx[0:8] | 조향 | 실속 | d |
|---|---|---|---|---|
| 5.54 | 3.6 3.6 3.6 … | +14.0° | 3.7 | +0.16 |
| 5.55 | 0.7 0.6 0.5 0.4 0.2 0 0 0 | +14.0° | 3.6 | +0.14 |
| **5.73~6.70** | **전부 0** | **+0.00°** | 2.9→0.7 | **+0.03 → −1.28** |
| 6.72 | 2.9 3.0 3.0 … | +2.8° | 0.3 | −1.36 |

그 구간 트랙 곡률은 κ≈0.55 (R≈1.8 m). 무조향 직진을 적분한 예측 d와 실측 d의
오차가 호길이 1.6~1.7 m에서 **8~9 cm** — 사실상 완전 일치한다.
164645에서는 4.25 → 전 점 0이 **단일 사이클(24 ms)** 안에 일어난다.

**수정안**

```cpp
// 조향 기하는 "차가 실제로 낼 속도"로 계산해야 한다. 계획 속도가 0인 정지
// 프로파일에서도 차는 여전히 달리고 있고, 그때 조향이 0이면 코너를 직진한다.
const double speed_for_lookup = speed_adjust_lat_err(
    std::max(steering_lookahead_speed, std::abs(speed_now)), lat_error_norm);
```

**검증 방법**: 재생 시 `곡선(|κ|>0.2)에서 조향==0 & v>1.5` 지속시간이 0이 되는지.
현재 164216 0.47 s / 164645 0.41 s / 164934 0.45 s → 목표 0.

> planning 쪽에서 트레일링을 계단 → 램프로 고쳤으므로(§5 P1) 노출 빈도는 이미
> 줄었지만, **근본 원인은 이 줄이다.** planning 수정만으로는 제거되지 않는다.

### C3. 백스톱의 가속 잠금

**위치** `control_node.cpp:928`

backstop_cap = std::min(backstop_cap, speed_now - over * (speed_now - 1.5));
